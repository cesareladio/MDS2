# NTT DATA Chile + Perú · One GDN-e

Experiencia web 3D interactiva construida con React, TypeScript, React Three Fiber, GSAP y Zustand.

## Ejecutar

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

La aplicación es estática y puede desplegarse en Cloudflare Pages, Vercel o Netlify usando `dist/` como carpeta de salida.
